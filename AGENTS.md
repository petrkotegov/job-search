# Работа с материалами поиска

- Для задач поиска работы сначала читай `private/README.md`: это индекс личных материалов. Затем открывай относящиеся к задаче документы по ссылкам из него.
- Запросы вроде «проверь по критериям» означают проверку по актуальному файлу критериев, указанному в `private/README.md`. Используй его текущую редакцию с учётом новых указаний пользователя; исторические диалоги служат источниками опыта и уточнений.
- При добавлении, переименовании или существенном изменении личных документов и наборов вакансий поддерживай `private/README.md` в актуальном состоянии.
- Личные материалы и результаты поиска сохраняй в `private/`, вне Git. В репозитории размещай только код инструментов, их документацию и общие инструкции.
